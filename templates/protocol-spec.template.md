# 检测设备串口协议（用户提供,逐字照用,勿自创）

## 链路
- 端口/波特率：<COMx @ 115200, 8N1>

## 帧格式
- 帧头 / 长度 / 命令字 / 数据 / 校验(CRC/checksum) / 帧尾
- <逐字段说明>

## 命令表
| 命令 | 方向 | 字段 | 含义 |
|------|------|------|------|
| <0x..> | 主机→检测设备 | ... | 触发/查询某通道状态 |
| <0x..> | 检测设备→主机 | ... | 回报真实测量值/状态 |

## 测试项（可扩展;协议同一份,项可增加）
- K1-CLOSE：查询继电器 K1 触点导通状态 → 应答 0/1
- OUT2-V：测 OUT2 电压 → 应答 mV
